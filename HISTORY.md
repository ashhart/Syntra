# Development history

This repository combines the Syntra application runtime and the Lycan language.
The first surviving Lycan commit is dated 15 May 2026, and the first surviving
Syntra commit is also dated 15 May 2026.
The May histories were recovered from archived development repositories after
the combined project had been imported into a new history on 7 September.

The restored branches preserve their original author and committer timestamps.
They are joined to the current implementation with a merge that retains the
current source tree; no development dates have been invented or backdated.
New QA and release-preparation commits use their actual dates.

Publication preparation changes historical commit hashes: identities are
normalized to the maintainer's GitHub noreply address, co-author trailers are
removed, old organization identifiers and machine paths are replaced, and a
webhook demo derived from a private operational export is excluded from every
published historical snapshot, including its compiled artifacts.
That demo is replaced in the current tree with an explicitly synthetic workload.
Historical snapshots are preserved as development history, not supported release
versions; only the current release candidate is covered by the current QA run.
